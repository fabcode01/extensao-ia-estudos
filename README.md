# Assistente de IA para Otimização de Estudos 📚

Este projeto é uma atividade de extensão universitária desenvolvida para a disciplina de **Inteligência Artificial para Devs**. O objetivo é aplicar conceitos de IA Generativa para resolver uma demanda real da comunidade: a dificuldade de organizar cronogramas de estudo eficientes.

## 👥 Impacto Social e Extensão
A ferramenta permite que estudantes que não têm acesso a tutorias particulares consigam estruturar seus estudos de forma lógica, democrática e totalmente gratuita.
